# Octane Software Solutions - Company Info & Credentials

## 1. Core Competency & Value Proposition
Octane Software Solutions is an APAC-focused consultancy specializing in financial planning database architecture (IBM Planning Analytics/TM1) and advanced AI agent integrations. 
*   **Key Advantage:** Flat-rate DevOps model that removes the distinction between development and support hours, eliminating scope-creep disputes.
*   **Target Market:** Finance departments, FP&A directors, and CFOs in logistics, retail, manufacturing, and media.

## 2. Customer Case Studies

### Case Study: Meridian Logistics (Transport & Distribution)
*   **Challenge:** Manual Excel budgeting and forecasting close took 4-5 days of manual effort. The FP&A team had to consolidate 35 separate departmental spreadsheets and reconcile them with NetSuite ERP actuals.
*   **Solution:** Implemented IBM Planning Analytics (TM1) and deployed the Octane **DataFusion NetSuite Connector** to automate transaction loadings. Deployed Power BI dashboards fed from the TM1 central repository.
*   **Results:**
    *   Saved 3 full days of manual close time per month.
    *   Eliminated version control errors and manual spreadsheet copy-pasting.
    *   Allowed financial analysts to focus on route-variance and capacity-planning metrics rather than manual data entry.

### Case Study: Global Retail Group (Multi-Channel Retail)
*   **Challenge:** Slow report load times (15-25 seconds) on legacy TM1 instances, exceeding the 5-second threshold. High RAM usage and unmanaged transaction log growth caused system lag during peak forecasting hours.
*   **Solution:** Conducted an Octane **TM1 Flight Check** system audit, optimized feeder memory rules, cleaned up transaction log directories, and transitioned the client to the **DevOps Blue Support** program.
*   **Results:**
    *   Reduced report load times to under 3 seconds.
    *   Decreased server RAM footprints by 35%.
    *   Established active monitoring alerts for log file clearance.
