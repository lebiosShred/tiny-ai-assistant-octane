# Competing Applications Playbook - Jedox

This document details the features, capabilities, and competitive differentiators of Jedox for Financial Planning and Analysis (FP&A).

## 1. Product Core & Architecture
- Scalable Integration: Automatically aggregates data for Profit and Loss (P&L), balance sheet, and cash flow in one platform.
- User Interfaces:
  * Easy-to-use Web Portal: Access ad hoc reports and dashboards directly online.
  * Excel Add-In: Full spreadsheet interface with code-free write-back capabilities to the central engine.
- Best Practice Accelerators: Pre-configured planning models to speed up configuration and deployment times.

## 2. Key Capabilities & AI Features
- Scenario Planning: Supports ad hoc scenario simulations and adjustments across all financial statements.
- Rolling Forecasts: Streamlines monthly or quarterly rolling forecast cycles.
- Zero-Based Budgeting: Built-in frameworks to rebuild budgets from zero, identifying savings.
- AIssisted Planning: Uses proprietary machine learning algorithms for predictive forecasting, outlier detection, and data-driven recommendations.

## 3. Key Competitor Advantages & Outcomes
- Excel Familiarity: Combines the flexibility of standard spreadsheets with enterprise data governance.
- Shortened Planning: Aggregates multi-location data automatically, reducing errors.
- Target Metric (C&A): Reduced budgeting and scenario planning time by 66%.
