# Complementary Applications Playbook - MS Excel (PAfE)

This playbook outlines the capabilities, benefits, and differentiators of integrating Microsoft Excel with IBM Planning Analytics (PAfE).

## 1. Core Integration Value
- Governed Excel: Combines the flexibility and user familiarity of Microsoft Excel spreadsheets with the security, scale, and performance of the TM1 multidimensional engine.
- Direct Connection: Access centralized data in real-time, eliminating manual copy-pasting or file merging.
- Create Once, Reuse: Reports are created once and automatically refresh with updated database figures each month.

## 2. Standalone Excel vs. Governed Excel (PAfE)
- Version Control: Standalone Excel relies on manual file-naming versions (high error risk). PAfE uses centralized database versions with full audit trails.
- Data Consolidation: Standalone Excel requires complex, error-prone formulas. PAfE consolidates data at the TM1 source in sub-seconds.
- Dataset Scale: Standalone Excel degrades under large datasets. PAfE queries multidimensional cubes on-demand.
- Collaboration: Standalone Excel has limited real-time collaboration. PAfE converts Excel spreadsheets into interactive web sheets for non-Excel users.

## 3. Key Features
- Drill Down: Double-click high-level summaries to view transactional line items.
- Security: Role-based access controls dictate cell-level visibility.
- Validation: Built-in error checking blocks invalid inputs.
