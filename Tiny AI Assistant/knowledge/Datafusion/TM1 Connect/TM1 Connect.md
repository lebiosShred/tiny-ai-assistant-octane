# TM1 Connect Marketing & Sales Playbook

This playbook outlines the business capabilities, sales strategy, and competitive advantages of TM1 Connect compared to Datafusion.

## 1. Core Value Proposition
* Relational Virtual Mapping: TM1 Connect converts multidimensional OLAP cubes into virtual SQL database tables, allowing traditional BI tools to query them.
* Business Analyst Mappings: Provides a visual administration console to define virtual tables.

## 2. Target Customer Profile
* Profile: Mid-to-large organizations running legacy BI reporting infrastructures that require relational SQL connection patterns.
* Buyer Personas: BI Manager, Reporting Lead, Database Administrator.

## 3. Marketing Value & Sales Pitch vs. Datafusion
* The Challenge: TM1 Connect requires setting up and maintaining dedicated middle-tier database servers, mapping schemas manually, and managing cache synchronization schedules.
* The Datafusion Solution: Datafusion requires zero middleware servers, zero complex database mapping, and connects directly as a lightweight stream.
* Sales Pitch: "Datafusion eliminates the infrastructure overhead of setting up and maintaining database gateway servers. It streams data directly from TM1 to BI tools in real-time, requiring no SQL mapping configuration. Choose Datafusion for a modern, lightweight, and cloud-ready direct connection."

## 4. Key Advantages & Business Features
* Graphical administration interface for database mappings.
* Respects user and cell-level security rules defined in the source TM1 database.
* Performance caching to help reduce redundant query load on the server.
