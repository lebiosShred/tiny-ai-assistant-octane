# TMVgate Marketing & Sales Playbook

This playbook outlines the business capabilities, sales strategy, and competitive advantages of TMVgate compared to Datafusion.

## 1. Core Value Proposition
* URL-Based Data Streaming: TMVgate streams TM1 cube data directly into BI tools using secure web URLs.
* Format Adaptability: Streams data directly in JSON, XML, CSV, or HTML.

## 2. Target Customer Profile
* Profile: Small-to-midsize businesses seeking a simple, low-code URL export method for BI tools.
* Buyer Personas: Finance Manager, Reporting Analyst, IT Support Lead.

## 3. Marketing Value & Sales Pitch vs. Datafusion
* The Challenge: TMVgate lack local data caching. Every report query hits the active TM1 server directly. This can cause high CPU utilization and freeze planning screens for users.
* The Datafusion Solution: Datafusion utilizes local caching and performance optimizations to stream data with zero impact on the core TM1 engine performance.
* Sales Pitch: "TMVgate streams data via URLs, but it does not protect your TM1 server performance. Multiple users running reports can slow down the core planning engine. Datafusion uses smart performance optimization to protect your server, ensuring that planning and reporting can run concurrently without slowdowns."

## 4. Key Advantages & Business Features
* Server-based component (requires no desktop client installation).
* Natively respects TM1 security modes and user access profiles.
