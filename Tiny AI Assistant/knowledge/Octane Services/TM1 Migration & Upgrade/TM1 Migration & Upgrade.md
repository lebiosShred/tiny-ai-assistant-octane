# TM1 Migration & Upgrade Playbook

Octane's migration service ports legacy, on-premises TM1 Perspectives applications to IBM Planning Analytics (TM1) Cloud.

## 14-Day Migration Roadmap
* Deliverable: A like-for-like replication of the client's TM1 Perspectives model in the IBM Cloud.
* Timeline: 14 days from contract signing (contingent on IT credentials and server access).
* Components Ported: Dimensions, cubes, data, rules, hierarchies, attributes, exception formats, reports, processes, and active data feeds.
* Included Reports: Conversion of five custom Excel reports to Planning Analytics for Excel (PAfE).
* Training: 4 hours of user training on the new platform interfaces.

## Comparison: Cloud vs. On-Premises

| Parameter | On-Premises (Perspectives) | Cloud (Planning Analytics/PAX) |
|---|---|---|
| Infrastructure | Managed locally (maintenance overhead) | Hosted and supported directly by IBM |
| Uptime | Depends on local server reliability | 99.7% guaranteed SLA |
| Performance | Restricted by local hardware bounds | Higher query speeds and scalability |
| Updates | Manual upgrades (requires downtime) | Continuous software updates |
| Security | Managed by internal network IT | Enterprise-grade IBM security |

## Exclusions & Limitations
* Licensing: Does not include IBM Cloud licenses (procured separately).
* Optimization: Model redesign, security alterations, debugging of pre-existing data errors, and performance optimizations are excluded (handled as post-migration projects).
* Report Limits: Includes five Excel reports. The migration team provides guidance to help users port any additional reports.
