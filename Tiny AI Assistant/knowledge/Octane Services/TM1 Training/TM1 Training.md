# TM1 & Developer's Training Playbook

Octane Software Solutions provides live and on-demand training modules via Kajabi for end-users, model creators, and system developers.

## End-User Training Modules
* Price: AUD $59 per module (on-demand access to all lessons for 30 days)
* Certification: Certificate of completion issued upon course completion.

### Course Syllabus

1. Planning Analytics for Excel (PAfE)
   * Focus: Excel-to-TM1 integration.
   * Content: Transforming Excel skills into TM1 capabilities, building dynamic reports connected directly to cubes, and running real-world TM1 exercises.

2. Planning Analytics Workspace (PAW)
   * Focus: Visual analysis and dashboard creation.
   * Content: Mastering PAW visualizations, designing interactive dashboards, and sharing analytics dashboards across teams.

3. Introduction to IBM Planning Analytics
   * Focus: Fundamentals for beginners.
   * Content: Navigation of web (PAW) and Excel (PAfE) interfaces, and understanding core components (cubes, dimensions).

## Developer's Training
* Focus: Advanced modeling, performance optimization, and automation.
* Pricing: Available as part of the TM1 Package Course (AUD $150, regularly $250).

### Advanced Course Syllabus
* Cube Rules in IBM Planning Analytics: Mastering syntax for rules, database functions, and memory feeders.
* Model Troubleshooting: Using the Trace tool to debug calculation issues and optimize query speeds.
* Automated Calculations: Eliminating Excel export steps by automating calculation logic directly in the TM1 engine.
